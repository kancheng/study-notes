性別變化

規律速記：常見有加 e（allemand → allemande）、-ais → -aise（français → française）、-ien → -ienne（italien → italienne）、-éen → -éenne（coréen → coréenne）；belge、russe、suisse、tchèque 陰陽同形；grec → grecque 為特殊形式。l’ 只是省音，不能用來判斷名詞性別。

例句

中文法文
我是法國人（男）。
我是法國人（女）。
我是臺灣人（男）。
我是臺灣人（女）。
我住在臺灣。
我出生於臺灣（男）。
我出生於臺灣（女）。
大小寫：國家名稱大寫（France、Japon、Taïwan）；國籍形容詞小寫（français、japonais、taïwanais）。Je suis français. 表示國籍時不加 le。國籍當「某國人」名詞用時會大寫，例如 un Français，勿與形容詞用法混淆。
荷蘭：課本使用 hollandais／hollandaise；指整個荷蘭也常用更精確的 néerlandais／néerlandaise。
